# Aura Botánica

Sitio web informativo de Aura Botánica, boutique de plantas ornamentales y diseño botánico.

Construido únicamente con HTML5 y CSS3, sin frameworks ni JavaScript.

    - style.css
  - img/
    - logo.png
    - productos/

## Páginas

- index.html — Presentación de la empresa y productos destacados
- nosotros.html — Historia, misión, visión, valores y equipo
- productos.html — Catálogo de productos agrupados por categoría
- contacto.html — Datos de contacto, horarios, mapa y formulario visual
- faq.html — Preguntas frecuentes sobre envíos y servicios

## Despliegue

Repositorio conectado a Azure App Service (Web App) mediante GitHub.
